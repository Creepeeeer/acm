左偏树是一种可并堆结构，支持两个堆的合并过程，时间复杂度为$O(logn)$

### 左偏树的定义

**每个结点的左儿子** **dist** **都不小于它右儿子的** **dist**

显然，上面的那张图中不是一棵左偏树，而下面这棵就是一棵左偏树（~~确实树如其名~~）

![img](https://cdn.luogu.com.cn/upload/image_hosting/oe7fkhbq.png)

不过，下面这棵树也是一棵左偏树，因为它满足左偏树的性质（图中红色数字标注了每个结点的 dist 值）。

![img](https://cdn.luogu.com.cn/upload/image_hosting/ofwei3xm.png)

所以，判断是否为左偏树也不能以偏~概全，而 这条性质被叫做左偏树的 左偏性质

由左偏性质还可以延伸出一条很重要的性质 ： 显然，一个结点的 dist 能且只能被它两个子结点中 dist 小的更新（想一想，为什么），而右儿子的 dist 永远比左儿子小，所以可以直接使用右儿子的 dist 来更新当前结点的 dist。

得到如下公式

$dist_i=dist_r+1$

### 合并操作（merge）

这个操作可谓是所有可并堆的灵魂所在了，理解它也很容易。左偏树的合并代码可以分为 3 部分（这里以小根堆为例）。

1. 把根结点权值小的堆（根为 x）作为基础，它的所有左儿子不做出改变，而把另一个堆（根为 y）和 x 的右儿子继续递归合并。
2. 递归到 x,y 中的一个为空结点时结束，返回不为空的结点编号
3. 更新 dist 值,且把不满足左偏性质的左右儿子互换。

具体图例如下：

![img](https://cdn.luogu.com.cn/upload/image_hosting/p3wtvxy4.png)

```c++
int merge(int x,int y){
    if(!x||!y)return x+y;
    if(!cmp(val[x],val[y]))swap(x,y);
    rs[x]=merge(rs[x],y);
    if(dist[ls[x]]<dist[rs[x]])swap(ls[x],rs[x]);
    dist[x]=dist[rs[x]]+1;
    if(ls[x])fa[ls[x]]=x;
    if(rs[x])fa[rs[x]]=x;
    return x;
}
```

### 弹出堆顶（pop）

把根结点的左右儿子合并，再维护一下并查集就好了，但有一些地方需要格外注意，先看代码

```cpp
int pop(int x){
    x=find(x);
    fa[ls[x]]=ls[x];
    fa[rs[x]]=rs[x];
    fa[x]=merge(ls[x],rs[x]);
    ls[x]=rs[x]=dist[x]=0;
    return x;
}
```



这里把根结点的权值定为 -1 来表示它被删掉了，同时维护左右子树的 fa 。 有些读者可能对这条语句很疑惑

```cpp
fa[x]=merge(ls[x],rs[x]);
```



x 不是被删掉了吗，为什么要多此一举地改变 $fa_x$，合并儿子不就行了吗？其实是因为这里只改变了根结点附近的 fa ，还有一些结点仍然认被删结点 x 为老大，所以让 x 认新合并出的根结点为老大，这样后面的结点自然也就认新根结点为老大了（老大的老大还是老大）。避免了并查集产生混乱。





左偏树不支持删除给定权值的数，如果要删除需要遍历整个堆，但是**可以删除给定编号的节点**,时间复杂度是$O(logn)$
